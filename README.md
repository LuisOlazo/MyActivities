# Coursera: Programa especializado: Desarrollo de aplicaciones móviles con Android

## Curso 3 - Module 2

Desarrolla una aplicación. 

Nota: Ésta debe ser diferente e independiente al proyecto que realizaste anteriormente "Integrando Material Design con identidad personalizada".

Haz una aplicación móvil que se compondrá de dos activities: 

**Activity 1**: Será un formulario de contacto donde solicites al usuario los siguientes datos:

- Nombre completo
- Fecha de nacimiento (picker de fecha)
- teléfono
- Email
- Descripción del contacto 

Todos los campos EditText deberán tener estilo de Material Design. 
Al final de todos los elementos deberá existir un botón de "Siguiente" que nos lleve a la próxima Actividad.

<img width="230" height="438" alt="image" src="https://github.com/user-attachments/assets/2a2bd4ac-3e1b-405d-b63f-931d66615b1f" />


**Activity 2**: Será una pantalla de confirmación de datos en donde se deberán mostrar todos los datos ingresados por el usuario. 

Al final de los datos, debes colocar un botón de "Editar datos". Este botón deberá llevar a la actividad anterior la cual tendrá los datos precargados en los campos para poder ser editados una vez más.

### Criterios de Evaluación
- Que utilice el elemento EditText de Material Design
- Que tenga los campos solicitados 
- Picker para la fecha
- Pantalla de confirmación de datos 
- Botón de "Editar datos"
- Datos precargados en el campo de texto al seleccionar "Editar Datos"
